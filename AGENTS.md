# rsudtangsel

Monorepo, 3 independent modules (no workspaces/hoisting; npm only). Root holds only `compose.yaml` (Postgres) + `.gitignore` + `.env.example`. Each module has its own `.gitignore`/`.env`.

Code comments, logs, and API messages are in Indonesian; git commits mix conventional prefixes (`feat:`, `refactor:`) with plain sentences.

## Modules

- `mobile/` — Expo SDK 57 (React Native), expo-router, TS strict. Read `mobile/AGENTS.md`: Expo v57 has breaking changes vs. training data — check https://docs.expo.dev/versions/v57.0.0/ before writing code. Verify with `npx tsc --noEmit` + `npx expo lint`.
- `server/` — Go 1.22 API. Entrypoint `cmd/api/main.go`. Clean architecture: `cmd/api` → `handler` → `service` → `repository` → `database` (sqlx). DTOs in `dto/{request,response}`.
- `web/` — Next.js 16.3.1 (App Router), Tailwind v4. `web/AGENTS.md` is auto-generated by `next dev`; don't delete the `BEGIN:nextjs-agent-rules` block.

## Web notes (run from `web/`)

- Verify: `npm run lint` (eslint). No standalone typecheck script — `npm run build` is the typecheck.
- Reuse the existing UI kit (`components/ui/*`: button, card, dialog, input, toast, stepper, …) instead of writing new components ad hoc.
- All user-facing strings go through i18n: `lib/translations.ts` (id/en) + `lib/i18n-context.tsx` — never hardcode UI text.

## Server rules & gotchas (run from `server/`)

- `server/PRD-BACKEND.md` is the backend spec/roadmap (MVP done; auth/JWT, jadwal dokter, chat, rekam medis planned) — read it before implementing endpoints.

- **Run**: `go run ./cmd/api`. The Makefile `run`/`build` targets still use `go run .` — broken since main moved to `cmd/api`; don't trust them.
- **Verify**: `go build ./... && go vet ./...`. No Go tests exist.
- **Env**: copy `server/.env.example` → `server/.env` (gitignored). `DATABASE_URL` is required; loaded via godotenv. Server port = `SERVER_PORT` env (default 8080).
- **DB**: `make db-up` (wraps `docker compose -f ../compose.yaml up -d db`) → postgres:16, container `rsudtangsel-db`, port 5432, named volume `postgres-data`.
- **Migrations** (golang-migrate, files in `server/migrations/`):
  - Names use **timestamp IDs** (`YYYYMMDDHHMMSS_name.up/down.sql`), not `000001`. Create with `make migrate-create name=foo`.
  - `make migrate-up` / `make migrate-down` (down 1 step) / `make migrate-force v=N`.
  - CLI runs via `go run -tags postgres github.com/golang-migrate/migrate/v4/cmd/migrate@v4.17.1`. The `-tags postgres` flag is **required** or you get `unknown driver postgres (forgotten import?)`. v4.17.1 is pinned because v4.19 requires go ≥ 1.23 (triggers toolchain download on this go 1.22 machine).
  - `make migrate-version` exits 1 with `no migration` when nothing is applied — normal, not an error.
  - Editing an already-applied migration will not re-run it. To reapply changed migrations on dev: `TRUNCATE schema_migrations` in the DB, then `make migrate-up`.
- **Response convention**: every HTTP response must go through `internal/utils` `SuccessResponse`/`ErrorResponse`, which encode the `dto/response` `GlobalResponseSuccess`/`GlobalResponseError` shape (`success`, `status_code`, `data`, `message`). Never write raw JSON in handlers.
- **API test**: `bash test_api.sh` (script has no +x). It needs a running server + migrated DB and **hardcodes** `BASE_URL=http://localhost:8080` (line 3) — env override is ignored. On this dev box :8080 is often taken by an unrelated process; use `sed 's|:8080|:9090|'` or free 8080. All 8 tests should pass.
- `server/api` (8.4 MB) is a **stale committed binary** — don't rebuild or re-commit it. `make build` outputs `bin/server` (gitignored). `.gitignore` covers `/server` and `/bin/`, not `/api`.

## Mobile gotchas

- `expo-env.d.ts` is gitignored and generated on first `expo start`. If missing, `tsc` fails on CSS imports — create it manually with `/// <reference types="expo/types" />`.
- `expo lint` reports one pre-existing template error (`src/hooks/use-color-scheme.web.ts`, `set-state-in-effect`) — not caused by user changes.

## Root

- `compose.yaml` + root `.env.example` are the source of truth for DB credentials; `server/.env.example` mirrors `DATABASE_URL`.
- `server/README.md` is the upstream golang-migrate README, not project docs — ignore it.
