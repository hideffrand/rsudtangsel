RSU Tangsel - Dokumentasi API

Referensi endpoint REST API backend. Format respons konsisten: { success, status_code, data, message }.

Format Respons

Base URL: http://localhost:8080 Semua respons: JSON 
{
  "success": true,
  "status_code": 200,
  "data": { ... },
  "message": "pesan opsional"
}

// Error:
{
  "success": false,
  "status_code": 400,
  "data": null,
  "message": "deskripsi error"
}

Tidak ada endpoint yang cocok.

Dokumentasi statis - dihasilkan dari definisi route di server/cmd/api/main.go dan handler-nya.
